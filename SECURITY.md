# Security Policy

Lavanda is pre-release software (Phase 1 of a multi-phase build-out) and
does not yet have a dedicated security contact or a public issue tracker
suitable for coordinated disclosure.

## Reporting a vulnerability

If you find a security-relevant issue (memory safety bug in the native
backend, resource lifecycle bug that could be triggered by an untrusted
caller, etc.), please do not open a public issue. Instead, contact the
maintainers privately and allow a reasonable window to investigate and
release a fix before any public disclosure.

This policy will be expanded (with a named contact and disclosure SLA)
once the project has a public repository and release process.
